## The method — Find-Its-Home (repeatable, all measurement)

Each closed signal runs five steps, none of which spends multiplicity: **confront** the old verdict
and its epoch → **characterize** the signal universe-wide (is the information real?) → **diagnose the
book-fit** (why did it die on *this* book?) → **locate the home** (which book shape's phase / horizon
/ turnover expresses it?) → **place it** (record "real, home = shape Y"), never kill. Only if a home
is found *and* it clears the activation bound does a candidate earn a gated trial. The template is
finding **0139** (delivery).

## The pattern that decides the review

**The homes converge on one thing: a second book shape with its own capital.** Delivery wants a
pre-breakout / breadth-50 vehicle; the zoo wants an own-capital breakout sleeve; USD-sensitivity
(A7) wants a portfolio ERC sleeve; low-vol (A6) *is* the first such sleeve, already live-logging. So
the campaign is not 13 unrelated studies — it is the **assembly of the signal set for the second
book** whose go/no-go is **§4 (breadth-50)**. The measurement half is unlimited and free; only the
book-building half is the gated, owner-capital decision everything funnels toward.

And the counter-examples are as valuable as the wins: **not every real signal is placeable.** PEAD is
real and structurally trapped; the zoo's edge is real but its sleeve economics are unfavorable. The
campaign will keep producing a *mix* of "found a home" and "stays closed" — which is the honest
calibration a blanket re-open would have missed.

## What §4 (breadth-50) should take from this

1. **Low-vol is live** — the first second-sleeve is forward-logging at 0.60; its Oct-1 first read is
   the earliest real evidence on whether the diversification free-lunch holds forward.
2. **Delivery has a named home here** — a pre-breakout / broad book is the vehicle that could express
   the delivery accumulation edge (0139); it does not belong on the momentum book.
3. **Residual momentum (A9) already has a live home** — the forward-wall veto-0.1 arm. No build
   needed; its Oct-1 read is part of the wall's evidence.
4. **PEAD, chart-zoo, USD, 52-week-high, and the GBM selector are all closed** — none is a live sleeve
   candidate. The zoo is the sharpest lesson (a real per-trade edge, own capital, still underperforms
   and fails to diversify — per-trade quality is not portfolio value), and A11 is the second: its
   defensive variant is dominated by the low-vol sleeve, which lifts Sharpe rather than cutting it.

## Final tally — the campaign's answer

**All 13 Category-A signals are placed: 3 homes, 10 closed.** And the shape of the answer is the
point:

- **The three homes were mostly already built.** Low-vol is live-logging (0.60); residual-momentum's
  veto is the production wall arm; only **delivery** points to something not yet built — and it points

- **The ten closures are ten real signals, each stopped by a real structural wall** — momentum-
  redundant (zoo, 52wh), momentum-entangled (PEAD), needs-a-short-side (USD), per-trade≠portfolio
  (GBM, conviction, HEG), or sub-floor single-feature (revenue-growth). Not one hides a usable overlay
  for the current book.

**The decisive conclusion for §4:** the current momentum book is *fully optimized* — every banked
signal that could improve it has now been re-examined on the current apparatus and fails on it. The
only place remaining value can live is the **second book shape (breadth-50)**, which is exactly where
delivery's home is and where the whole campaign converges. Building that book is therefore not one
option among many; it is *the* lever that unlocks the single remaining unrealised home. All of this
at **zero trials and zero screen rows**.

## Category-B — owner decision (2026-08): do NOT bulk re-run

Unlike the Category-A sweep (all measurement, zero cost), a Category-B re-run is a **trial**: each
re-tests an old *book-level* config for a promote/kill decision, so it increments `n_trials` and
runs on the same 2017–2026 windows, raising multiplicity exactly as the amendment warns. Bulk-running
the 23 would take `n_trials` 2 → ~25 — **re-poisoning the Deflated-Sharpe bar the 2026-08-07 reset
deliberately lowered** — for a **modal outcome of UNDERPOWERED** (n_eff≈37 → dSharpe half-width ~0.59,
below these effects). The reset note is explicit: *"do not read the reset as a licence to re-run dead
tests on the same data."*

**Decision (owner, this campaign): leave Category-B as quotable priors.** Reopen an individual item
only when a specific one becomes decision-relevant, pre-registered properly at that point (pre-reg
committed → counter incremented → run → verdict). The signal sweep (Category-A) is the substantive
result; the book-level re-runs add cost, not information. `n_trials` stays **2**.
